# Hospital Management System

A simple Hospital Management System built using Python and File Handling.

## Features

* Add Patient
* View Patients
* Search Patient
* Update Patient Details
* Delete Patient Records

## Technologies Used

* Python
* OOP (Object-Oriented Programming)
* File Handling
* Loops and Conditions

## File Structure

hospital.txt - Stores patient records

Format:

PatientID,PatientName,Disease,DoctorName
